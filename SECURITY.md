# Границы безопасности

Это однопользовательский локальный прототип. Сервер слушает 127.0.0.1. В нём нет SaaS-аутентификации, изоляции компаний и прав отдельных пользователей. Публикация исходников не означает готовность сервера к публикации в интернете.

Используйте отдельный SQL-логин с SELECT только на выбранные представления. Генератор допускает ограниченный план запросов и параметризует значения, однако это не заменяет ограничение прав на стороне SQL Server.

## Что не публиковать

- `.env`, ключи API, пароли, строки подключения с секретами.
- `config.json` с адресами и именами реальных источников.
- `business_context.json`: структура и бизнес-описания тоже могут быть конфиденциальны.
- `data/`, снимки экрана, экспорты, логи, резервные копии и внутреннее ТЗ.

Эти рабочие файлы исключены из Git. Перед первым push проверяйте `git ls-files` и `git diff --cached`. `.gitignore` не удаляет файл из существующей истории. Если секрет уже опубликован, его нужно отозвать/заменить; удаления последнего файла недостаточно.

## Передача Gemini

Исходный шаблон запрещает внешние вызовы. Значение `question_and_schema` в `ai.external_data_policy` разрешает отправку текста вопроса, метаданных, пользовательских описаний и предыдущего плана. Строки запросов и результаты SQL не отправляются. Чувствительные значения, введённые в вопрос или описание, являются частью отправляемого текста.

Условия обработки и бесплатные квоты определяет Google. Из API-ключа приложение не может определить статус биллинга. Не помещайте ключ в frontend, URL или Git.

При сообщении об ошибке прикладывайте обезличенный пример и технические сведения. Не публикуйте реальные ключи, запросы с персональными данными или снимки бизнес-отчётов в публичном issue.
